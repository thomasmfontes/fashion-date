# Fashion Date

Plataforma do Fashion Date Crente Chic para cadastro de lojistas, geração de números da sorte e realização do sorteio Provador Fashion.

## Funcionalidades

- Cadastro por QR Code com nome, loja, WhatsApp e Instagram.
- Número da sorte único para cada participante.
- Bloqueio de cadastros duplicados pelo telefone.
- Painel administrativo com busca e exportação.
- Sorteio ao vivo preparado para exibição em telão.
- Histórico de vencedores.
- Banco de dados persistente com Cloudflare D1.

## Desenvolvimento

Requer Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Para validar a versão de produção:

```bash
npm run build
```
